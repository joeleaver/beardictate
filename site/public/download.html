Download beardictate

Free, and yours to keep. The download is small. On first run, beardictate fetches its speech and cleanup models (about 1.3 to 3 GB, depending on your computer) and from then on dictates offline.

This is an alpha

While beardictate is being tested, every copy sends its developer what happens when you dictate, so problems can be found and fixed and the next cleanup model trained on real dictation: the recordings of what you dictate and the text recognized from them; the spoken commands, the cleanup’s text before and after, and what was typed; timings, warnings and errors, your settings, and your computer’s operating system, processor, memory and graphics card.

Only what you say while dictating is sent. With “Always listening” on, nothing said while beardictate is asleep leaves your computer, and nothing you type yourself is ever sent. It’s tied to a random install number, not your name or any account, waits in a folder on your computer (at most 220 MB) until it’s sent, and is deleted there once it has been. Please don’t dictate anything you wouldn’t want the developer to read or hear.

Build it from source on Linux

If the Linux download doesn’t run on your system (it needs a very recent one), you can build and install beardictate yourself. You need a Rust toolchain, CMake and a C++ compiler. The script installs it for your user only, under ~/.local, and adds it to your app menu.

git clone https://github.com/joeleaver/beardictate
cd beardictate
scripts/install-linux.sh --autostart

Leave out --autostart if you don’t want it to start when you log in.

Check your download

Each file has a SHA-256 checksum next to its download button. If the checksum of the file you downloaded matches it exactly, the file arrived complete and unchanged.

Windows (PowerShell)

Get-FileHash .\beardictate-…-setup.exe

Linux

sha256sum beardictate-…

macOS

shasum -a 256 beardictate-…

What your computer needs

Any 64-bit computer from the last several years with 8 GB of memory will run it. With 16 GB or a graphics card, it picks a larger cleanup model that handles dialog better. The help page has the details.
