# beardictate

Local, offline dictation for writers: hold a hotkey, talk, and clean prose —
punctuated, de-ummed, with dialog properly quoted — is typed into whatever app
has focus. Windows first-class; Linux and macOS too. UI in rinch.

Status: design sketch. See [DESIGN.md](DESIGN.md).
